## ?? Overview

**Expense Pulse** is a personal finance tracker designed for mobile web (iOS / iPhone) and native Windows desktop. It seamlessly synchronizes with your personal **Google Sheets** spreadsheet using the Google Apps Script Web API, ensuring your financial data remains 100% private, free, and under your ownership.

Featuring a high-contrast **Neubrutalist + Liquid Glass Hybrid Design**, Expense Pulse provides instant financial clarity, transaction history management, monthly spend summaries, and system notifications.

## ? Key Features

* ?? **Google Sheets Live Sync**: Read & write transactions directly to your personal Google Sheet.
* ?? **Mobile-First Neubrutalist UI**: Engineered for iPhone 16 Pro Max, mobile Safari, and desktop displays.

## ??? Tech Stack & Requirements

### System Requirements:
* **Operating System**: Windows 10 / 11 (for Desktop App) or any modern Web Browser (iOS Safari, Chrome, Edge).
* **Node.js**: v18.0.0 or higher.
* **Google Account**: For hosting your personal Google Sheet.

### Technologies Used:
* **Frontend**: HTML5, CSS3 (Neubrutalism Tokens & Liquid Glass Glassmorphism), Vanilla ES6+ JavaScript.
* **Charts & Icons**: Chart.js, Remixicon (`cdn.jsdelivr.net/npm/remixicon@3.5.0`).
* **Desktop Application**: Electron v34.5.8, `electron-builder`, `electron-updater`.
* **Cloud Hosting**: Firebase Hosting.
* **Backend Storage**: Google Sheets API via Google Apps Script Web App.
